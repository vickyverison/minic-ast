# Синтаксичний аналізатор MiniC

Навчальний проєкт із системного програмування. Реалізовано лексичний і синтаксичний аналіз підмножини мови C засобами Flex і GNU Bison.

## Можливості

- побудова абстрактного синтаксичного дерева (AST);
- виконання програми та обчислення виразів;
- перевірка оголошення й ініціалізації змінних;
- генерація коду мовою Python;
- серіалізація AST у JSON і його візуалізація у браузері.

Підтримуються змінні `int`, арифметичні вирази, порівняння, присвоєння, блоки, `if`, `else`, `while` та `printf("%d\n", expression);`. Це підмножина C: функції, масиви й вказівники не підтримуються.

bison -d parser.y
flex lexer.l
